# Afyktos — Music
GitHub Pages-ready music portfolio matching the visual system of the existing Afyktos Art & Design portfolio.

## Before publishing
1. In `index.html`, replace the Spotify `href="#"` with the final Afyktos Spotify artist URL.
2. Replace the Apple Music `href="#"` with the final Afyktos Apple Music artist URL.
3. Replace `YOUR_EMAIL_HERE` with the preferred contact email.
4. Replace the typographic release placeholders with real cover images whenever ready.

Recommended path: `https://afyktos.github.io/music/`
